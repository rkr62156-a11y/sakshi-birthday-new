PUBLISH AS A BRAND-NEW GITHUB REPOSITORY
1. On GitHub, create a NEW repository. Example name: sakshi-birthday-new
2. Set it to Public. Do not add a README, .gitignore, or license (this package already has its files).
3. Open the new empty repository and choose Add file > Upload files.
4. Extract this ZIP on your phone/computer first. Upload the CONTENTS of the extracted folder, not the ZIP itself. The files index.html, style.css, app.js, README.txt and all five PNG photos must appear directly in the repository root.
5. Commit the upload to the main branch.
6. Open Settings > Pages. Under Build and deployment, choose Deploy from a branch; select main and /(root), then Save.
7. Wait for the Pages deployment to finish. Open the URL shown on the Pages settings screen.

IMPORTANT
- Keep all five image files in the same root folder as index.html.
- File names are case-sensitive; do not rename them.
- This version does not depend on a backend or external JavaScript libraries.
- Music links open Spotify searches after a tap. Browsers generally block sound autoplay, so music is user-initiated.
- The secret code is visible in the JavaScript source; it is a playful gate, not real password security.
